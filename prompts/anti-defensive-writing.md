# 去除防御性写作（发布会原则）

论文是发布会，不是工作汇报。每一句都要推进论证；只为了防住质疑的句子，删掉。

写、改、审都按这个原则执行。

## 识别：防御性写作的 8 个特征

1. 自我削弱的词：unfortunately, only, merely, limited, modest, still lags behind, we acknowledge, it should be noted that。
2. 结论刚下，立刻解释它不意味着什么："This only shows ... and does not prove ..."。
3. 把试错过程当叙事："We first tried A, it did not work, so we switched to B."
4. 限定词堆在句首，或单独成句："On one fold, ..."、"In ablations with ..., ..."。
5. 替审稿人总结弱点：先认一个弱点再反驳；主动提醒对手没调参（untuned, without tuning）。
6. 优势藏着不说：正文只报弱的一面，强的数字放补充材料；说"我们最好"，却不给数、不给对手。
7. 输掉的指标裸摆着，没有放进真实的权衡。
8. 一节的最后一句停在最弱处，比如停在一个不显著的 p 值上。

## 处理：每一处只有三个办法

- 删：只为防质疑、不推进论证的句子；和前文重复的句子。
- 改写：换成正面说法，数字不变。限定词从句首挪到句尾，或并进定义。输掉的那一项写成两个并列事实，或写成真实的权衡。
- 挪：范围、限定、没赢的比较，挪到表注、图注或补充材料。

## 叙事：发布会写法

1. 主线围绕最强优势展开；试错过程是工作日志，不进正文。
2. 每个实验都要有论证职责，没有职责的删掉。
3. 优势主动说清楚：表里赢得最硬的数字，正文要有一句话把它说出来。
4. 打不赢的指标，换评价维度或比较口径，不设成比赛。
5. 不占优的结果，从目标差异或合理权衡解释，写成权衡而不是输。
6. 摘要和引言做成发布会开场：问题、缺口、思路、最硬的结果。
7. 每节最后一句停在这一节的主张上；结论只强化记忆点。

## 检查流程

1. 每段先写一行：这段在回答什么。
2. 逐句标注作用；标不出作用的句子就是候选。
3. 每个候选从删、改写、挪里选一个执行，改写的给出替换的英文。
4. 查漏掉的优势：表里赢得最硬的数，正文有没有一句话把它说出来。
5. 改完对着表格把数再核一遍。

## 底线

- 只改强调、顺序和措辞，不改事实；数字不动。
- 没用的、与主结论相悖的内容可以删；局限留哪几条，由作者自己定。
